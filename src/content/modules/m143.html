1. Description

In any current-carrying circuit, the current produces a magnetic field through the loop of the circuit. If a magnetic field through that same loop varies with time, there is induced in that loop an \({\cal EMF}\) which drives a current around that loop. It thus follows that if a current in a circuit varies with time (such as when it is first turned on) it produces a time-varying magnetic field which in turn induces an \({\cal EMF}\) (with a corresponding current) in this same circuit. This induced \({\cal EMF}\) drives a current around the loop in such a direction as to oppose the change associated with the changing current that gave rise to it. Therefore, to merely set up a current requires the expenditure of energy. This energy can be viewed as going to set up the magnetic field that results. This energy is the topic of this module.
