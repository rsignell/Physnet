1. INTRODUCTION

This is the last unit in your introduction to the theory of complex variables and its applications to physics and engineering. The Cauchy Residue Theorem is of powerful use in evaluating many of the integrals which regularly occur in physics and enginering.

3. SUPPLEMENTARY NOTE

At various times, the residues of the function \(f(z) = 1 / z^n + b\) at each of the poles are needed.

It is easy to calculate the residue using L'Hospital's rule. Thus, if \(z_0\) is a pole of \(f(z)\), then,

\[a_{-1} = {\rm lim}_{z \rightarrow z_0} \fract{(z - z_0)}{z^n + b} = {\rm lim}_{z \rightarrow z_0} \fract{d/dz (z - z_0)}{d/dz (z^n + b)}\]

\[a_{-1} = {\rm lim}_{z \rightarrow z_0} \fract{1}{n z^{n-1}} = \fract{1}{n z_0^{n-1}} = - \fract{z_0}{nb}\]

Since \(z_0^n = -b\) so that \(1 / z_0^{n-1} = - z_0 / b\).
